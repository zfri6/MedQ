# MedQ v0.1 交付说明（2026-10-27）

本版交付的是可复现的仿真与真实IP接入工程，不是已通过实板验收的成品。
压缩包：deliverables/MedQ_v0.1_20261027.zip；相邻.sha256核对压缩包；内含DELIVERY_MANIFEST.json逐文件SHA256。

## 本版包含

- rtl/：完整MedQ源码、字体初始化数据、原始PLL/SDRAM IP与加密控制器。
- tb/：25项自动检查与冻结参考；tb/vendor/提供真实控制器/PLL模型检查。
- sim/*.py：命令行复现、来源哈希、结果判定与冻结打包脚本。
- prj/constr/：当前40bit引脚基线与SDC草案；prj/td/含批处理驱动和三次物理打包失败的原始证据。
- doc/：当前契约、集成说明、验证边界和下一步；历史文档以日期和更新提示区分。
- 每项ModelSim编译/运行日志，真实SDRAM/PLL/ODDR结果，以及整机PPM完整截图。

解压到普通本地目录，从该目录运行README列出的命令。修改doc/hw/toolchain.json中的工具路径即可适配另一台已安装工具的Windows电脑；不要定义SIMULATION来做TD综合。
工程XML随每次运行生成绝对路径；批处理在新的ASCII临时目录运行。交付中的旧运行XML仅为证据，使用脚本重新生成当前机器工程。

## 已验证

25/25常规ModelSim PASS，112项输入哈希一致。SDRAM适配器逐字核对1311个返回数据；整机含原加密控制器跑通SD素材、CRC命令、按键去抖、三次叫号、27段语音、HDMI编码与完整视频帧，5174次物理刷新。
1x1/3x3一般缩放及640x480直通，两种扫描方向和反压，共1228800个像素精确匹配。FIFO与队列RAM有顺序、满空、回绕、反压/并发、复位和恢复检查；20张UI帧与原基线相同。
整机SDRAM测试仍用行为时钟和行为串化器；真实PLL/ODDR分别另测，未声称全部原语共同仿真。
这些是仿真与综合证据，不是板上观测。SD测试使用缩小合成FAT32，PLL/ODDR为厂商功能模型，SDRAM器件侧为独立行为模型，无电气时序或信号完整性证明。
