# 使用说明

## 启动

将下载文件写入开发板，并将 SD_ROOT 内全部文件放入 FAT32 TF 卡根目录。连接 HDMI 显示设备后上电，系统显示欢迎封面。按任意 K 键进入诊室界面，松开按键后开始业务操作。

## 取号与叫号

K1、K2 分别办理 A、B 诊室初诊取号，K3、K4 分别办理 A、B 诊室回诊取号。初诊编号分别以 A、B 开头，回诊编号分别以 C、D 开头。

SW1、SW2 分别控制 A、B 诊室叫号启停。暂停叫号期间仍可取号，候诊人数、回诊人数和字幕继续更新。

## 患者到诊

SW3、SW4 分别用于 A、B 诊室患者到诊及就诊结束操作。两间诊室分别处理自己的患者状态。

## 显示与声音

屏幕显示患者编号、脱敏姓名及目标诊室；语音播报患者完整姓名。两条字幕各自对应一间诊室，操作提示即时刷新后向左连续滚动。

诊室地图下方自动轮播医生照片，每次显示一张，采用淡入淡出过渡。右下角波形反映实际播报声音。语音通过 HDMI 输出。

## TF 卡文件

| 文件 | 用途 |
|---|---|
| COVER.BMP | 欢迎封面 |
| DOC01.BMP、DOC02.BMP | 医生照片 |
| CLIP00.PCM 至 CLIP53.PCM | 语音素材 |

全部文件直接放置在 TF 卡根目录。图片采用 640×480、24 位无压缩 BMP 格式。
