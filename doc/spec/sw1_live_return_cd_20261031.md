# SW1仅控叫号及C/D回诊票修订

- SW1极性保持：SW[0]=0允许叫号，=1停止叫号。停止时不发首次/重呼grant，等待计时和播放进度保留且静音；取号、到位/离开、人数、服务状态及两条上方字幕继续更新。
- K1/K2为A/B普通队列，K3/K4为C/D回诊队列。A/B/C/D各自01..99，不共享编号；每室普通/回诊各16人容量和严格回诊优先不变。
- C/D只替换患者票前缀，不改变目标诊室：请C01号到A诊室就诊，请D01号到B诊室就诊。室徽标/导诊图继续为A/B。
- QSTATE原位域不变；[22]/[54]的回诊标志与BCD共同构成完整票号。音频取消事务也带回诊类别，避免A01/C01或B01/D01串扰。
- 字模仍为4K、2bit四级覆盖度；采用矩形空隙装箱容纳新增C/D字形，不缩小原字形或增加BRAM窗口。A/B原像素覆盖度与冻结参考逐点比较。
