# MedQ V0.3 操作说明（2026-11-01事件字幕）

|板上开关名|RTL端口/引脚|功能|
|---|---|---|
|SW1|SW[0] / C8|低电平允许A叫号，高电平停止A叫号|
|SW2|SW[1] / C7|低电平允许B叫号，高电平停止B叫号|
|SW3|SW[2] / C6|每次稳定拨动：A患者到位，再拨动离开；空闲忽略|
|SW4|SW[3] / C5|每次稳定拨动：B患者到位，再拨动离开；空闲忽略|

开机采用全部开关初值为基线，不误触发医生事件。SW3/SW4是拨动事件，高低本身不是患者状态。SW丝印序号仍待实板核对，端口/引脚沿用冻结ADC。

K1..K4=KEY[0..3]，分别A普通/B普通/A回诊/B回诊。四类独立A01..99/B01..99/C01..99/D01..99；C到A诊室，D到B诊室；每种等待队列16人，回诊严格优先，当前患者不抢占。

任一诊室停止叫号：仅该室的新叫号/重呼/过号/30秒计时暂停；仍可取号并增加候诊/回诊人数，医生仍可办理到位和离开；两条字幕、人数、状态、动画持续更新。另一室正常叫号。暂停当前播放时先静音并安全排空已发SDRAM事务，让共享音频服务另一室；重新开启后为同一患者重播完整语句，不再出队或增加呼叫次数。期间医生改变患者状态则丢弃旧语句，不重播。

字幕示例：请A01***到A诊室就诊；请B01***到B诊室就诊；回诊请C01***到A诊室就诊/请D01***到B诊室就诊。三个ASCII星号为患者姓名占位。语音仍读号码与目标诊室，不朗读星号。

呼叫按实际grant开始，0/30/60秒最多三次，第三次后再等30秒未到结束；争用可延后。医生同拍优先。扬声器语音由HDMI屏幕/电视或其音频口输出；板上BUZZER仅无语音时有限提示音。尚无实板听音证据。

TF卡仍使用原21个CLIP00.PCM..CLIP20.PCM，无需因本次字幕改动重新生成音频。空FAT32根目录按编号顺序复制，仅PCM，不放WAV或其他PCM；加载器按目录枚举顺序，不按文件名排序。格式16000Hz、有符号16bit小端单声道；922256字节。缺卡明确进入有限提示音模式。

UART保留ACK/NAK/CRC及命令5参数；旧取号/下一号/重呼命令不接入新业务。无持久化、原票号查询、第二屏或热插拔恢复。board_test: not_tested；本次不下载。


两条字幕分别显示A/B诊室最新操作：普通/回诊取号成功、取号失败、开启/暂停叫号、叫号/重呼/恢复实际开播、患者到位、就诊结束、未到过号。操作在下一帧显示，统一从字幕左缘x24开始，随后向左移动；两室相位独立，另一室不会被重置。短于一帧的连续同室操作显示最新一条，不排队播放过时提示。

举例：A01***取号成功，请候诊；C01***回诊取号成功，请候诊；A诊室已暂停叫号；请A01***到A诊室就诊；A01***已到位，就诊中；A01***就诊结束；A01***未到位，已过号。B对应B/D。新操作提示仅改变字幕，原语音仍只播号码与诊室。
