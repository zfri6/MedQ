# R08 暂停恢复边界实现说明

R08原有要求不变：暂停期间的业务输入不受理、不缓存、不补发。每个输入的armed在暂停时清零；恢复后4个25MHz周期的同步余量，且raw/candidate/stable一致，才允许新事件。尚未完成的消抖变化先静默更新基线，再重新武装，防止恢复后延迟补发。时钟、消抖计数、输入基线继续运行。

新增定向TB保留同一预期，确证先前已签核输入RTL失败，而修复后的相同TB通过；负控制日志和SHA见doc/compile/v03_resume_negative_control.json。该测试不作为新STA或位流证据，最终源码仍须全回归、真实顶层、新原生构建及新bitgen。
