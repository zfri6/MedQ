1 概述 
本文档主要介绍了TangDynasty®（以下简称TD 软件）软件中时序约束工具Timing Wizard 和静态
时序分析相关的各类报告Check-Timing Report、Timing Report、Logic Level Report、Clock Tree 
Report、Clock Inter Section Report 的界面操作和使用。通过此文档，可协助用户在设计过程中完
成系统的时序约束，并通过静态时序分析中的各项报告对设计系统的时序进行了解与分析其性能是否
满足时序要求。 
2 时序约束工具 
TD 软件的时序约束工具Timing Wizard，是用于辅助用户对设计进行时序约束的工具。 用户对设计
进行时序约束有两种方式：第一种，通过添加SDC 文件，SDC 文件可用户新建并写入SDC 命令或添加已
有 SDC 文件；第二种，通过 Timing Wizard 界面设置时序约束。本文档仅详细介绍如何通过 Timing 
Wizard 进行时序约束设计的方法。 
2.1 Timing Wizard 启动方式 
当 Flow 运行完成 Syn Opt 的 Optimize RTL ，并执行 Open Run 操作后，才可打开时序约束界面
Timing Wizard，否则处于置灰即不可操作状态。 
鼠标点击TD 主界面菜单栏Tools，在下拉菜单中点选Timing Wizard。如下图所示。 
 
图 2-1 Timing Wizard 启动方式 
此时会弹Warning 窗口，如下图所示，提示更改Timing Wizard 不会导致重启运行Optimize RTL 
stage。如果不想更改 Timing Wizard 点击 Cancel 按钮进行取消，点击 Continue 即可打开 Timing 
Wizard 主界面。

2.2.1.2 Create Generated Clock 
Create Generated Clock 设置界面，用于定义一个派生时钟，设置派生时钟Generated Clock 与
主时钟Master Clock 的频率与相位（边沿）关系，并生成相应的SDC 命令create_generated_clock。
Generated Clock 属于Master Clock 所在的时钟域，在时序报告中也将具有和 Master Clock 相同的
时序起点。 
点击Create Generated Clock，进入其设置界面，如下图所示。 
 
图 2-14 Create Generated Clock 设置界面 
界面中相关参数所设值必须保证正确有效， 否则设置界面的Apply 按钮置灰，无法进行创建。相关
参数设置如下所示： 
 Clock Name: 指定派生时钟名，不可缺省。 
 Master Pin：指定生成时钟的驱动时钟源点，即Master Clock 所在的源点，该源点可以是物
理上存在的任意时钟节点，点击 Master Pin 的下拉菜单，系统会列出设计中所有已存在的时
钟节点，选择需要的时钟源点即可。 
 Master Clock：指定时钟源点上的驱动时钟，同一个时钟源点可能会被创建了多个不同时钟，
因此需要指定约束目标的驱动时钟是哪一个，单击 Master Clock 的下拉菜单， 选择需要的时
钟即可。  

=== PDF PAGE 14 ===

 Source Objects：用于指定生成时钟的约束对象，可通过单击右侧search 符号，在弹出的窗
口中选择需要的时钟节点，可通过get_ports、get_pins、get_nets 进行过滤筛选。 
 Add：指定对同一生成时钟约束对象进行多次约束，可以约束为不同的频率、不同的相位或不
同的占空比。在该时钟节点上已有约束的情况下， 如果省略该参数， 则新的约束覆盖已有的约
束命令。 
 By Clock Frequency：如果勾选此项，则基于时钟频率关系的方式设置生成时钟，将可通过分
频参数Divide source clock frequency by 或倍频参数Multiply source clock frequency 
by 来设置，并配合Phase 参数调整相位。与By Clock Edges 设置存在互斥关系。 
 Divide source clock frequency by：指定生成时钟和驱动时钟的分频系数，数值为正, 默认
值为1.000，数据格式支持小数点后三位。与Multiply source clock frequency by 设置存
在互斥行为。 
 Multiply source clock frequency by：指定生成时钟和驱动时钟的倍频系数，数值为正，默
认值为1.000，数据格式支持小数点后三位。与Divide source clock frequency by 设置存
在互斥行为。 
 Duty Cycle：配合Divide source clock frequency by 选项使用， 用以调节生成时钟占空比，
默认值为50 即50%，取值范围是0～100。 
 Invert waveform：用于配合By Clock Frequency 选项使用，勾选该选项，为将生成时钟的
波形反转。 
 By Clock Edges：如果勾选此项，则基于时钟相位关系的方式设置生成时钟，将可通过时钟沿
对应关系参数Edge List 和时钟沿偏移参数Edge Shift List 来设置。与By Clock Frequency
设置存在互斥关系。 
 Edge List：指定生成时钟的沿与驱动时钟的沿的对应关系，界面中三个框，分别指定新生成
时钟的第一个上升沿，第一个下降沿，第二个上升沿对应驱动时钟的相应边沿。 
 Edge Shift List：该选项仅在-edge 选项设置正确才有效，用于指定生成时钟的沿与驱动时
钟的沿的偏移关系。 界面中三个框的所设值为整数， 单位为ns， 该值的正负表示偏移的方向，
为正时向右偏移，为负时向左偏移。 
 Phase Value：指定生成时钟波形的相位移动，默认值为0，取值范围是0～360 之间，数据格
式支持小数点后三位。

2.2.4.3 Set Multicycle Path  
Set Multicycle Path 界 面 ， 用 于 设 置 允 许 多 个 时 钟 周期 延 时 的 时 序 路 径 约 束 ， 即 生 成
set_multicycle_path 的SDC 命令。通常情况下，两个同步的寄存器进行Setup 时序检查时，路径中组

3.4.2.2 时钟树拓扑结构 
时钟树是由许多缓冲单元(buffer)及其相互连接关系搭建的树状结构。树根表示时钟信号的源点，
叶子即时钟终端表示电路中时序器件 （如寄存器） 的时钟引脚。 树干部分表示从时钟源点到时序器件的
时钟引脚所需经过的布线以及缓冲单元。 信号从时钟源点传播到时序器件的时钟引脚的过程中， 经过多
级缓冲器（数量根据设计需要而定） ，因此，时钟树中叶子结点的高度可能不一。 
展开Clock Tree Report 中某一个时钟树，第一级为时钟树名，括号内统计该时钟树内有多少个
时钟；第二级为时钟树内各时钟名，括号内显示该时钟频率和时钟类型；第三级分为TOPOLOGY(时钟网
络拓朴结构)和MAX_SKEW(最大时钟偏差)。
